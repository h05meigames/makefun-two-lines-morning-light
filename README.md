One original two-line micro poem about light and morning, written for the
[u-gudril-cool-two-lines-of-morning-light-ade94fc5](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5)
bounty on [make.fun](https://make.fun/r/0ene8b3q).

## The poem

> Morning slips a pale thread under the door—
> and the dark floor learns, stitch by stitch, to shine.

## How it works

`main.ts` (Node 22, standard library only) writes the poem to
`/output/entry.txt` — exactly two lines, 98 characters, UTF-8, no trailing
newline, within the 120-character limit.

## Run it

```sh
node main.ts
```
